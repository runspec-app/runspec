Help UI.
The helpdesk UI focuses on a catalogue of runnables and is not replacing instant chat systems. 
Each user of UI gets assigned to a queue, when signing up, queue system then always assigns automatically to the available operators based on a fair system that fits what we can build. Every 'chat' is driven by first selecting a runnable.

Help UI catalogue of runnables.
Catalogue is a display of all available runnables of all operators connected and on shift at the time which means one operator might be the only one with some runnables in their catalogue and selecting that runnable from UI has to be assigned to them always. Also that means that sometimes some runnables won't appear.
We don't want to replace instant messaging, do we even need chat, we're build a runnables catalogue UI really.
