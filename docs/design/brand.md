# runspec brand

The brand chosen in November 2026 (the "Gate" direction). The design boards
live in a claude.ai canvas; this page is the part the code and docs follow.

## Positioning

runspec is for application support and DevOps teams in regulated
environments. Instead of giving an agent a shell or a sandbox, you give it,
and your team, an **allow list of tools**. Each tool has its autonomy set in
advance, and every run is on record.

- Agents with a shell or a sandbox are good tools for other jobs (we use them
  too). Present runspec as a different job, never as "safer than" them.
- Keep the agent out of the subject position. People, forms and schedules run
  tools as much as the agent does.
- Keep "SSH" out of brand and positioning copy: some readers hear "hacker
  tool", others assume the agent can reach any server. Say "the servers
  you've added". SSH belongs in the technical pages that explain how it works.

## Lines

| Line | Where it goes |
|---|---|
| **You decide what runs.** | The brand line: README, site hero, About box |
| **Approved tools, not a shell. Every run on record.** | Directly under the brand line |
| **Fast where it's safe. Careful where it counts.** | Autonomy, Forms and agent pages |
| **Automation you sign off on.** | Security and audit pages, regulated readers |
| **Describe it once. Run it safely anywhere.** | The spec on its own (authoring pages) |

## The mark

A run triangle behind a vertical gate bar: tools can run fast, but only
through a gate you control. Round-ended bar, triangle with softened corners
(variant G1). Source geometry, in a 48×48 box:

```text
bar       line (12,9) → (12,39), width 4, round caps
triangle  (20,12) (38,24) (20,36), filled, 2px round-join stroke
```

- **On dark:** bar in chalk `#e8ebef`, triangle in teal `#3cc7b6`.
- **On light:** bar in slate `#111418`, triangle in deep teal `#0e8f80`.
- **As an icon (tile):** the mark knocked out in white on a rounded deep-teal
  tile, slightly heavier so it holds at 16 px. Generated by
  `runspec_console/brandmark.py`; the docs favicon is
  `docs/assets/favicon.svg`.

The mark can also show state (the console doesn't do this yet): amber bar =
an approval is waiting, faded bar = running, outlined triangle = paused.

## Wordmark and family

- **runspec** in Inter Bold, lowercase, tight tracking (about −0.04em), next
  to the mark.
- Products add a plain second word in a lighter weight: **runspec** console,
  **runspec** tui, **runspec** marketplace.
- Runnable packs (`runspec-linux`, `runspec-jira`, …) are names only, in
  mono, with no mark.
- **White-label:** a customer's brand replaces the mark, the name and the
  accent everywhere (icon, title bar, sidebar). At most a small grey "built on
  runspec" in an About box or footer.

Green and amber are kept for approve and wait, so "safe" shows in the UI and
not only in the copy.

## Type

Inter for words, JetBrains Mono for anything you could type: runnable names,
arguments, servers, logs. Both are already bundled in the console.

## Voice

Calm, plain, accountable.

1. **Name who, what and where.** "Restart `nginx` on web-01 as svc-ops?", not
   "The agent would like to perform an action."
2. **Ask, don't announce.** "This changes a server. Approve and run?", never
   "Running…" before anyone agreed.
3. **Say what didn't happen.** "Denied. Nothing ran on web-01.", not "Action
   cancelled."
4. **Plain words, no hype.** "Turns a script into a form, a CLI and an agent
   tool.", not "Supercharge your ops with seamless AI magic."

Words we use: runnable, approve, deny, server, fleet, run as, autonomy, on
record. Words we avoid: magic, autopilot, seamless, supercharge, leverage,
AI-powered.
