# credentials

## Notes

Credentials (Settings → Credentials) keep secrets in the OS keychain; only names and metadata are in config. A credential is applied as name-derived environment variables (label Jira gives JIRA_USERNAME and JIRA_PASSWORD) or bound to a runnable's username and secret args.
