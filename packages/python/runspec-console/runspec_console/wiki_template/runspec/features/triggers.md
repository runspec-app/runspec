# triggers

## Notes

Triggers react to events (new mail, a pasted block of text, a chat-room message, a schedule) either with a rule that runs runnables or with an agent turn. They respect the Rota (working hours, breaks, screen lock). The agent can edit them from chat with manage_triggers and manage_rota.
