# runspec cli

## Notes

The runspec CLI: runspec init scaffolds a runnable, runspec local lists the runnables installed in a venv, runspec test is the wiring gate for CI, runspec stubs writes typed stubs, runspec exec runs a runnable with a full run record, runspec serve exposes a venv as an MCP server, and runspec emit --rundeck / --ansible generates jobs and modules.
